Codex Mac Backup

供拥有者个人使用的 macOS 备份工具。它通过 Google Drive 桌面客户端保存本地配置、项目和会话快照，再使用本机 rclone 校验云端文件并轮换旧快照。

A personal macOS backup tool. Google Drive for desktop uploads local configuration, project and session snapshots. A local rclone process verifies cloud files and rotates older snapshots.

此网站仅介绍工具，不提供登录或备份文件访问。

This information site does not offer sign-in or access to backup files.
